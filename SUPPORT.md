# Support

This is a solo-maintained organization (see [GOVERNANCE.md](https://github.com/licorsy/.github/blob/main/GOVERNANCE.md)'s
Ownership section) — there is no formal support SLA. Response times are
best-effort.

## Asking a question

Use the [licorsy org Discussions board](https://github.com/orgs/licorsy/discussions)
for usage questions, ideas, or general feedback that isn't a bug or a concrete feature
proposal.

## Reporting a bug or requesting a feature

Use the repository's issue templates:

- **Bug report** — something in this project's governance, docs, or tooling is broken
  or not working as documented.
- **Feature request** — a change or addition to this project's process, docs, or
  tooling.
- **Unexpected agent behavior** — an AI agent (orchestrator, reviewer, or other
  subagent) did something unexpected.

See [CONTRIBUTING.md](https://github.com/licorsy/.github/blob/main/CONTRIBUTING.md) for how proposed changes move from issue to
implementation (the Change-as-prompt principle).

## Security issues

Do not open a public issue for a security concern — see [SECURITY.md](https://github.com/licorsy/.github/blob/main/SECURITY.md).
