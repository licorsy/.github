# Support

This is a solo-maintained organization — there is no formal support SLA. Response
times are best-effort.

## Asking a question

Use a repository's **Discussions** tab (when enabled) for usage questions, ideas, or
general feedback that isn't a bug or a concrete feature proposal.

## Reporting a bug or requesting a feature

Use the repository's issue templates:

- **Bug report** — something is broken or not working as documented.
- **Feature request** — a change or addition you'd like to see.

See [CONTRIBUTING.md](CONTRIBUTING.md) for how proposed changes move from issue to
implementation (the Change-as-prompt rule).

## Security issues

Do not open a public issue for a security concern — see [SECURITY.md](SECURITY.md).
